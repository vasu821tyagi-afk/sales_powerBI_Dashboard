
# HR Analytics Dashboard – Attrition Analysis

An interactive **Power BI HR Analytics Dashboard** designed to analyse employee attrition and identify key workforce trends.

### Key Analysis

* Overall employee attrition rate
* Attrition by **age, gender, and marital status**
* Attrition by **job role and department**
* Salary, tenure, and salary hike analysis
* Interactive KPIs and visualisations

### Tools Used

**Power BI | Power Query | DAX | Data Visualization**

This project demonstrates how HR data can be transformed into **actionable insights to support employee retention and HR decision-making**.
